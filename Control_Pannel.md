# The User Interface
- Here we will be describing the workings and rudimentary visuals of the interface which will allow
  personnel of the institution to be able to access and view and comprehend the information that is logged
  by the interraction between the hardware and the database.

- The interface is what will alow the user to work with the data that is being recorded with the initially in the "Student" database,
  the inputs from the hardware which will be stored in the "Log" database and the "Home" database  which will accomodate long periods of absence.

- The Whole interface will have universal panels "Log", "Out", "Systems Control", "Requests" and "Home", which will be discussed below.



## Log Panel

- This is the major part of the inteface with multiple options and customizable viewing, it will allow the admin or the admin adjacent
  to move through the data swiftly and get any information in any way they please.

- This will mainly operate by engaging(Creating and recording) with the "Log" database and
  will collect informations "Name", "Roll No.", "Program", "Role" from the "Student" database with the help of indexing throught the inputs by
  the hardware, which will be "Fingerprint", "Entry Time" and "Exit Time".
